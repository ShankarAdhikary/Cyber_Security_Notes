# Cybersecurity Notes for Students

An open-source collection of cybersecurity notes, resources, and practical references for students, beginners, and anyone interested in learning cybersecurity.

This repository currently contains **OSINT (Open-Source Intelligence)** notes and will continue to grow with contributions from students and the open-source community.

## Who Is This For?

- Students beginning their cybersecurity journey
- CSE/IT students preparing for internships, hackathons, and CTFs
- Self-learners exploring OSINT, networking, web security, and more
- Anyone who wants clear, practical, and organized study notes

## Contents

- [OSINT Notes](./OSINT/)

### Planned Topics

- Networking fundamentals
- Linux and Windows security
- Web application security
- Penetration testing
- Digital forensics
- Cloud security
- Malware analysis
- AI/ML security
- CTF writeups and tooling

## How to Use

1. Browse the topic folder you want to learn.
2. Use the notes for revision, practical learning, or CTF preparation.
3. Follow responsible cybersecurity practices and test only systems you have permission to access.

## Contributing

Contributions are welcome from all students and open-source contributors.

You can contribute by:

- Adding new topic notes
- Improving existing explanations
- Fixing errors or outdated resources
- Adding useful tools, labs, and learning paths
- Sharing CTF writeups and practical examples

### Contribution Steps

1. Fork this repository.
2. Create a new branch:
   ```bash
   git checkout -b add-topic-name
   ```
3. Add your notes in the relevant folder.
4. Commit your changes:
   ```bash
   git commit -m "Add notes on [topic]"
   ```
5. Push to your fork and open a pull request.

Please keep notes beginner-friendly, well-structured, and educational.

## Code of Conduct

Be respectful, inclusive, and supportive. This repository is meant to help students learn together in a safe and positive environment.
